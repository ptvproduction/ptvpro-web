# PTV Hub Design Pack Revisi 03

Paket untuk menetapkan standar isi PTV Hub dari HTML referensi sebelum menerapkannya ke aplikasi. Ini bukan theme siap install dan tidak berisi kode aplikasi produksi.

1. Ekstrak ZIP ke folder referensi/documentation pada project Hub.
2. Jadikan PTV-Hub-Guide-R03.md rujukan aktif. Update link panduan pada dokumentasi/AGENTS.md; simpan panduan lama sebagai arsip bila perlu.
3. Berikan MASTER-PROMPT-R03.md ke Antigravity. Jalankan tahap A dahulu dan laporkan hasil audit; jangan langsung menerapkan tokens.css secara global.
4. Setelah implementasi ditugaskan, jalankan katalog, pilot, dan migrasi komponen sesuai tahap B-D.

Scope: isi ptvpro.com/hub. Login tetap persis. Root launcher dan app lain terpisah.
CSS/JSON merekam primitive sumber, termasuk font stack Inter-first sebagai fakta ekstraksi. Keputusan target tetap SF Pro yang tersedia pada aplikasi, dengan continuous corner sebagai adaptasi terpusat. Semua aksi dan data demo dikecualikan dari migrasi.
